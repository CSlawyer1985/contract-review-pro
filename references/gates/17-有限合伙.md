## 17. 有限合伙企业合伙协议专项审查门禁

当主工作流类型路由步骤识别为有限合伙企业合伙协议时，在通用门禁之外同步核查以下专项事项。与通用门禁并行，不替代。

> **法律依据**：《合伙企业法》(2006修订) 第2-3、16-18、60-83条。法条引用使用前须检索验证现行有效性。

### 17.1 合伙人资格与出资结构

- **普通合伙人（GP）资格限制**（《合伙企业法》第3条）：国有独资公司、国有企业、上市公司及公益性事业单位/社会团体不得成为普通合伙人
- **合伙人人数**：2-50个合伙人，至少1个普通合伙人+1个有限合伙人（《合伙企业法》第61条）
- **有限合伙人出资限制**（《合伙企业法》第64条）：有限合伙人不得以劳务出资，普通合伙人可以劳务出资
- **非货币出资评估**：实物、知识产权、土地使用权等非货币出资须经全体合伙人协商作价或委托法定评估机构评估
- **出资方式、数额、缴付期限**：是否在合伙协议中明确约定，防止出资违约

### 17.2 利润分配与亏损分担

- **利润分配**（《合伙企业法》第69条）：有限合伙企业可以约定将全部利润分配给部分合伙人（与普通合伙企业不同）。分配方式应明确：按认缴/实缴出资比例、优先提取公积金比例、分配时点和方式
- **亏损分担**（《合伙企业法》第33条）：不得约定将全部亏损归于部分合伙人（该约定无效）。未约定时默认按实缴出资比例分担
- **GP无限连带责任**（《合伙企业法》第2条）：普通合伙人对合伙企业债务承担无限连带责任——是否已评估GP的无限责任暴露风险
- **LP有限责任**：有限合伙人以其认缴的出资额为限承担责任。注意：如LP实质参与合伙事务执行，可能丧失有限责任保护（《合伙企业法》第68、76条）

### 17.3 合伙事务执行与表决

- **事务执行权**（《合伙企业法》第67-68条）：由普通合伙人执行合伙事务，有限合伙人不执行合伙事务、不得对外代表合伙企业。合伙协议是否明确了各GP的事务执行权限边界
- **表决方法**（《合伙企业法》第30条）：是否约定了表决权分配（按人头/按出资比例/其他），重大事项是否需要全体一致同意
- **LP安全港规则**（《合伙企业法》第68条）：有限合伙人的哪些行为不视为执行合伙事务（如参与利润分配决策、建议更换GP、查阅财务账簿等），是否在协议中予以明确以避免LP丧失有限责任保护

### 17.4 入伙、退伙与身份转换

- **入伙条件**（《合伙企业法》第77条）：新入伙的有限合伙人对入伙前债务以认缴出资额为限承担责任；新普通合伙人对入伙前债务承担无限连带责任
- **退伙情形**（《合伙企业法》第45-49条）：是否区分约定退伙/当然退伙/除名退伙，退伙时的财产份额退还方式
- **身份转换**（《合伙企业法》第82-84条）：普通合伙人↔有限合伙人互相转变条件（原则须全体一致同意）。转变后的债务责任延续：GP转LP后仍对转变前债务承担无限连带责任
- **财产份额继承**（《合伙企业法》第50、80条）：合伙人死亡时的继承规则——普通合伙人继承人：须经全体合伙人一致同意才能取得GP资格，否则退还财产份额；有限合伙人继承人：可直接取得LP资格

### 17.5 竞业禁止与关联交易

- **普通合伙人竞业禁止（法定）**（《合伙企业法》第32条）：GP不得自营或与他人合作经营与本合伙企业相竞争的业务，不得同本合伙企业进行交易（全体合伙人一致同意除外）
- **有限合伙人自由竞争（默认）**（《合伙企业法》第70-71条）：LP可以自营或合作经营与本合伙企业相竞争的业务，可以同本合伙企业进行交易——合伙协议可以对LP行使此权利加以限制
- **财产份额出质**（《合伙企业法》第72条）：LP可以出质其财产份额（合伙协议另有约定除外）；GP出质须经其他合伙人一致同意

### 17.6 解散清算与争议解决

- **解散事由**（《合伙企业法》第85条）：是否覆盖法定的8种解散情形+约定的解散事由。特别注意：仅剩有限合伙人时应当解散（第75条）；仅剩普通合伙人时转为普通合伙企业
- **清算程序**：清算人指定方式（全体合伙人/过半数指定/法院指定）、清算期间（15日内确定清算人）、债权人申报期限、财产清偿顺序（费用→工资→税款→债务→分配）
- **争议解决**：多合伙人结构的争议解决机制是否合理——仲裁是否优于诉讼（保密性、专业性、效率）

### 17.7 有限合伙专项风险标签

| 标签 | 触发条件 |
|------|----------|
| `GP无限责任` | 普通合伙人无限责任暴露风险未评估或未隔离（如由客户关联方直接担任GP） |
| `LP劳务出资` | 有限合伙人以劳务出资（违法——《合伙企业法》第64条） |
| `利润分配不公` | 约定将全部亏损归于部分合伙人（该约定无效），或利润分配方式缺失 |
| `LP执行事务` | 有限合伙人实质参与合伙事务执行，面临丧失有限责任保护的风险 |
| `身份转换` | GP↔LP转变程序不清，或转变后的债务责任延续未明确 |
| `出资瑕疵` | 合伙人非货币出资未经评估，或出资缴付期限约定不明 |
| `解散清算` | 解散事由不完整、清算程序缺失，或仅剩LP时未触发解散机制 |
