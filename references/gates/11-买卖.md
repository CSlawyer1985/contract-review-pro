## 11. 买卖合同专项审查门禁

当主工作流类型路由步骤识别为买卖合同时，在通用门禁之外同步核查以下专项事项。与通用门禁并行，不替代。

### 11.1 标的物与交付标准

- 标的物的名称、规格、型号、数量是否明确（《民法典》第 596 条），是否足以确定合同标的
- 交付标准是否具体可验证（技术参数、质量标准、样品封存），是否存在仅以"合格""符合要求"等空泛表述替代具体标准
- 包装方式是否明确（第 619 条），涉及特殊运输（危化品、冷链、精密仪器）时包装标准是否匹配
- **主物与从物**：涉及从物交付的，从物是否随主物一并转移（第 320 条）；涉及单证和资料的，交付范围和时限是否明确（第 599 条）
- **一批/多批交付**：多批交付情形下，各批的交付时间、验收节点和解除规则是否清晰（第 633 条）

### 11.2 验收标准与检验期限

- **检验期限**（第 621 条）：约定的检验期限是否合理（不得短于买受人发现瑕疵的客观需要期间），过短检验期是否存在排除买受人异议权的格式条款风险
- **质量异议期**（第 622-623 条）：检验期限与质量异议期是否区分，通知程序（书面/口头/时限/接收方）是否明确
- **逾期未异议后果**（第 621 条第 2 款）：是否约定了买受人未在检验期内提出异议即视为标的物合格的条款；出卖人知道或应当知道标的物不符合约定时，该期限限制是否被排除（第 621 条第 3 款）
- **隐蔽瑕疵**（第 621 条第 2 款但书）：是否保留了买受人在质量保证期内就隐蔽瑕疵主张权利的空间；凭样品买卖中是否约定了隐蔽瑕疵排除条款（第 636 条）
- **验收程序**：验收由谁组织、以什么方式（单方/双方/第三方检测）、验收合格的书面确认形式、验收费用承担

### 11.3 风险负担与所有权转移

- **风险转移时点**（第 604-611 条）：风险转移时点与交付时点的对应关系是否明确；涉及需要运输的标的物（第 607 条）、路货买卖（第 606 条）、在途标的物等特殊情形是否约定清晰
- **所有权转移时点** vs **风险负担时点**：两者是否一致；如不一致（如约定了所有权保留），风险负担方的义务和责任是否匹配
- **交付地点**（第 603 条）：交付地点是否明确，涉及承运人运输时交付地点是出卖人所在地还是买受人所在地
- **买受人拒绝接收**（第 610 条）：标的物质量不符合要求致使不能实现合同目的时，买受人拒绝接收或解除合同的权利是否被合同条款限缩
- **代收/第三方收货**：涉及买受人指定第三方收货时，收货人的签收效力、检验义务和通知义务是否明确

### 11.4 所有权保留与权利瑕疵担保

- **所有权保留**（第 641-643 条）：约定是否明确（标的物范围、保留期限、价款支付比例与所有权转移的对应关系）；是否已办理登记（第 641 条第 2 款——未经登记不得对抗善意第三人）；出卖人取回权的行使条件和程序（第 642 条）及买受人回赎权（第 643 条）是否完整
- **权利瑕疵担保**（第 612-613 条）：出卖人是否保证标的物上不存在第三人的所有权、抵押权、租赁权、知识产权等权利负担；买受人知道存在权利瑕疵时是否放弃了相应救济权利（第 613 条）
- **知识产权瑕疵**：标的物涉及技术成果、软件、设计图纸等时，是否约定了知识产权无侵权保证和侵权时的赔偿责任

### 11.5 特殊买卖规则

- **分期付款买卖**（第 634 条）：分期付款的期数和金额；加速到期条款——买受人未支付到期价款达到全部价款 1/5 时，出卖人是否可以要求支付全部价款或解除合同；解除后标的物的使用费计算
- **凭样品买卖**（第 635-636 条）：样品是否封存并双方签字确认；样品质量与文字说明是否一致（不一致时以何者为准）；隐蔽瑕疵是否被排除
- **试用买卖**（第 638-640 条）：试用期限和试用标准是否明确；视为购买的条件（沉默/继续使用/支付部分价款）是否约定；试用期间的风险负担和保管义务归属
- **招标采购**（如涉及国企/政府）：是否适用《招标投标法》及实施条例；中标合同的实质性内容是否与招标文件一致；是否存在"阴阳合同"或背离招投标实质性内容的补充协议
- **出卖人回收义务**（第 625 条）：涉及电子电器、电池等需回收产品时，是否约定了出卖人的回收义务

### 11.6 买卖专项风险标签

| 标签 | 触发条件 |
|------|----------|
| `验收标准` | 验收标准模糊、检验期限过短或与质量异议期混淆 |
| `质量异议` | 质量异议的通知程序缺失、异议期不合理或被默示同意条款架空 |
| `风险负担` | 交付与风险转移时点不一致，或运输/在途/代收情形下风险归属不明 |
| `所有权保留` | 所有权保留约定存在但未登记（无对抗效力），或取回权/回赎权安排缺失 |
| `分期付款` | 存在分期付款安排但未触发或限制第 634 条 1/5 加速到期规则 |
| `权利瑕疵` | 标的物可能存在第三人的抵押、租赁、知识产权或其他权利主张，且合同未约定瑕疵担保救济 |
| `样品封存` | 凭样品买卖未封样，或样品与文字说明不一致时未约定优先规则，或隐蔽瑕疵未排除 |
