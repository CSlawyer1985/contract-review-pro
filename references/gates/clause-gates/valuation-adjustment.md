# 对赌/业绩补偿条款专项检查门禁（条款级）

> 按条款触发加载。当合同含业绩承诺、估值调整、业绩补偿、对赌安排时加载本门禁，与合同类型专项门禁（如 `../13-股权转让.md` 第13.4节、`../20-VCPE增资.md`）并行。
>
> 分析模式：维度 × 检查点 → 风险 → 按立场输出。

---

## 触发条件

合同文本出现以下任一表述时触发：对赌、业绩承诺、业绩补偿、估值调整、VAM、利润保证、净利润不低于、复合增长率承诺。

## 检查方法（强制）

逐检查点核对，每点输出三要素：**检查点结论 → 连接风险 → 按立场输出意见**（立场取自审核会话中声明的立场）。

## 维度一：对赌主体与效力

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 1.1 | 对赌相对方：与目标公司对赌 vs 与股东/实际控制人对赌 | 九民纪要第5条：与公司对赌有效但履行受减资/利润分配规则限制；与股东对赌一般有效 |
| 1.2 | 与公司对赌时的履行路径（减资程序/可分配利润审查）是否写明 | 无履行路径=判决支持但执行落空 |
| 1.3 | 是否存在变相保底安排被认定无效的风险（如明股实债争议） | 固定回报+不参与经营可能定性为借贷 |

## 维度二：业绩指标设计

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 2.1 | 指标可衡量性：净利润（扣非/不扣非）、收入、GMV、用户数——定义与计算口径是否明确 | 口径不明=争议制造机；扣非与否差异巨大 |
| 2.2 | 审计标准与审计机构选定机制 | 双方各自委托审计结果冲突时以谁为准 |
| 2.3 | 承诺期间与递延安排（单年考核 vs 累计考核） | 累计考核对融资方更友好（丰歉互补） |
| 2.4 | 不可抗力与情势变更豁免（疫情、行业政策剧变） | 无豁免条款则纯商业风险全压融资方 |

## 维度三：补偿机制

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 3.1 | 补偿方式：现金/股权/估值调整（增资价格追溯调整） | 股权补偿涉及无偿/低价转让的税务核定风险 |
| 3.2 | 补偿公式要素完整性（承诺值、实际值、投资额、持股比例的代入关系） | 公式缺失要素导致无法执行 |
| 3.3 | 补偿上限（如以投资额为限/以股权为限） | 无上限补偿=超额负担可能被法院酌减（公平原则） |
| 3.4 | 补偿与回购的并用/择一/冲抵关系 | 双重获利争议高发区，必须写明 |
| 3.5 | 多年补偿是否可递延冲抵（先补后退或先退后补的处理） | 逐年补偿后次年超额完成能否回补 |

## 维度四：程序保障

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 4.1 | 业绩确认程序：报表提交期限、审计时限、异议期 | 程序缺失导致"是否达标"长期悬置 |
| 4.2 | 异议解决机制（共同委托第三方审计/专家裁定） | 双方各执一词时的出路 |
| 4.3 | 补偿支付期限与逾期责任 | 无期限=补偿义务实质落空 |
| 4.4 | 融资方的信息披露配合义务边界 | 过度配合义务影响公司正常经营 |

## 维度五：失效、调整与恢复

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 5.1 | 后续融资时对赌条款的调整（新投资人是否承继、是否重签） | 多轮叠加导致对赌义务层层加码 |
| 5.2 | IPO 申报时的中止/终止/恢复条款 | 未清理影响上市审核；恢复条款（上市失败恢复效力）的处理 |
| 5.3 | 控制权变更时对赌义务的承继 | 创始人退出后是否仍担对赌义务 |

## 按立场输出（二分）

**代表投资人**：
- 必守：对赌主体包含股东/实控人（效力稳妥）；指标口径明确（扣非与否写明）；补偿公式可算；与回购的冲抵关系写明
- 可谈：单年 vs 累计考核；补偿方式；不可抗力豁免范围

**代表融资方/创始人**：
- 必守：补偿上限（以投资额/股权价值为限）；累计考核；不可抗力豁免；创始人个人责任封顶
- 可谈：指标高低；审计机构选定；回补机制

## 输出格式

每个检查点标注状态：✅ 覆盖 / ⚠️ 缺失 / 🔴 不利 / 💬 需谈判，批注以审查者视角提出具体问题（如"扣非与否是否写明？""业绩补偿与回购是否冲抵？"）。
