# 回购条款专项检查门禁（条款级）

> 按条款触发加载。当合同含回购/赎回/股权回售安排时加载本门禁，与合同类型专项门禁（如 `../20-VCPE增资.md` 第20.3.1节、`../13-股权转让.md` 对赌部分）并行。
>
> 分析模式：维度 × 检查点 → 风险 → 按立场输出。

---

## 触发条件

合同文本出现以下任一表述时触发：回购、赎回、回售、Redemption、要求收购、强制转让（与投资退出联动时）。

## 检查方法（强制）

逐检查点核对，每点输出三要素：**检查点结论 → 连接风险 → 按立场输出意见**（立场取自审核会话中声明的立场）。

## 维度一：触发条件

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 1.1 | 触发事件清单（未按期合格 IPO、重大违约、违法违规、其他投资人行权、重大不利变化） | 清单是回购制度核心；逐项审查客观性与可控性 |
| 1.2 | 触发事件是否含**不可控情形**（不可抗力、法律政策变化、行业环境变化） | 创始人立场：不可控情形必须排除，否则等于无条件保底 |
| 1.3 | 触发标准是否客观可判定（"重大违约""重大不利变化"是否有定义或量化标准） | 主观标准=争议制造机，行权与否各执一词 |
| 1.4 | 宽限期与补救机会（违约触发时是否有 cure period） | 无宽限期则轻微违约即引爆回购 |

## 维度二：价格机制

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 2.1 | 回购价格公式：本金+回报率（单利/复利、利率水平 8%-15% 区间合理性）+已宣告未付股息 | 复利+高利率对融资方是重负担；公式要素缺失导致计算争议 |
| 2.2 | 是否有"与公允价值孰高"条款 | 投资人保护加强项；融资方立场应争取删除或设上限 |
| 2.3 | 不同触发情形是否差别定价（违约触发可高于 IPO 未果触发） | 差别定价的合理性——违约高息具有惩罚性，可能被调减 |

## 维度三：义务主体与效力（核心风险区）

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 3.1 | 义务人结构：公司回购 / 创始人回购 / 连带 | 直接决定效力路径与风险归属 |
| 3.2 | **目标公司回购的效力审查**：是否约定减资前置程序（九民纪要第5条） | 约定"公司直接回购"而无减资安排的，司法实践中可能无法强制执行；投资人立场必须补程序路径，融资方立场须知该约定实际约束力存疑 |
| 3.3 | 公司回购是否涉及资本维持原则障碍（回购资金来源限制） | 公司以资本公积金/净资产回购可能触及变相分配 |
| 3.4 | 创始人连带责任是否有上限（以股权价值为限/个人财产无限） | 无上限连带=个人破产敞口；创始人立场必守项 |
| 3.5 | 多义务人之间的追偿与分担安排 | 连带后内部追偿不明=创始人之间二次争议 |

## 维度四：程序与顺位

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 4.1 | 行权期限与失权安排 | 无期限约束=义务长期悬置 |
| 4.2 | 多投资人回购顺位：同一顺位按比例 vs 后轮优先 | 创始人立场争取同一顺位；顺位不明导致部分投资人先行抽逃 |
| 4.3 | 支付安排：一次性/分期、支付担保（股权质押/资产抵押） | 分期+无担保=回购权实质落空风险（投资人侧） |
| 4.4 | 替代救济：无力支付时是否触发拖售/清算等替代路径 | 回购不能时的第二通道是否闭环 |

## 维度五：与对赌的联动

| # | 检查点 | 风险提示 |
|---|--------|---------|
| 5.1 | 业绩补偿（对赌）与回购是否并用、择一或冲抵 | 双重获利争议（已获业绩补偿部分是否冲抵回购本金利息） |
| 5.2 | 反稀释调整后的回购价格基数是否联动 | 基数不联动=重复保护 |

## 按立场输出（二分）

**代表投资人**：
- 必守：公司回购的减资程序路径写明；回购价格公式完整可算；支付担保或替代救济闭环；行权期限合理
- 可谈：利率水平；分期安排；宽限期长短

**代表创始人/公司**：
- 必守：排除不可控触发情形；创始人责任上限（以股权价值为限）；同一顺位；cure period
- 可谈：利率与单复利；差别定价；担保方式

## 输出格式

每个检查点标注状态：✅ 覆盖 / ⚠️ 缺失 / 🔴 不利 / 💬 需谈判，批注以审查者视角提出具体问题（如"公司回购的减资程序如何安排？""创始人连带是否有上限？"）。
