## 14. 承揽合同专项审查门禁

当主工作流类型路由步骤识别为承揽合同时，在通用门禁之外同步核查以下专项事项。与通用门禁并行，不替代。

### 14.1 验收标准与成果交付

- 工作成果的验收标准是否具体、可量化（不得仅有"验收合格""满足要求"等空洞表述）
- 验收程序是否明确（验收申请 → 验收期限 → 验收结论出具 → 逾期未验收后果）
- 验收不合格的整改义务和整改期限是否明确
- 成果交付后的风险转移时间点（交付时/验收合格时）是否明确

### 14.2 定作人任意解除权

- 是否对定作人任意解除权（《民法典》第 787 条）作出特别约定（排除/限制/约定赔偿范围）
- 如未排除，是否约定了解除后的赔偿计算方式（已完成工作部分的报酬 + 材料成本 + 预期可得利益）
- 解除权行使的时间节点限制（是否区分开工前/进行中/近完成阶段的不同赔偿方案）
- 承揽人是否有对应的救济机制（如定作人迟延提供材料或指示时的工期顺延和费用补偿）

### 14.3 承揽/劳动/劳务关系区分

- 是否包含独立关系声明（明确约定双方为独立的承揽关系，不构成劳动/劳务/合伙关系）
- **劳动关系三要素判断**（承揽人人员是否与定作人之间产生事实劳动关系风险）：
  1. **出勤管理**：个人是否接受单位的考勤管理（朝九晚五出勤或出勤有要求）——承揽关系下个人工作相对自由、不受严格出勤管理
  2. **社保缴纳**：单位是否为个人缴纳社会保险——只有用人单位有法定义务为其员工缴纳社保，如单位缴纳社保则基本可认定为劳动关系
  3. **固定报酬**：单位是否每月固定发放报酬——承揽人自担风险，报酬通常与成果挂钩而非固定周期发放
  - 注意：具备上述任一项即可能被认定为劳动关系（非承揽），即使合同名称写"劳务协议"也不改变实质定性
- **竞业限制无需补偿**：劳务/承揽关系不受《劳动合同法》竞业限制规定的约束，约定竞业限制时无需支付额外补偿（与劳动关系不同）

### 14.3B 人身损害赔偿与侵权责任

> 法律依据：最高人民法院《关于审理人身损害赔偿案件适用法律若干问题的解释》(2022修正)第十条 `[法条原文]`；《民法典》第1193条 `[法条原文]`。

- **承揽人侵权责任基本规则**：承揽人在完成工作过程中对第三人造成损害或造成自身损害的，定作人不承担赔偿责任（《民法典》第1193条 + 人身损害赔偿司法解释第10条）
- **定作人过失例外**：定作人对定作、指示或者选任有过失的，应承担相应的赔偿责任。合同中应考虑加入：
  - "乙方（承揽方）不得以甲方的指示、安排作为要求甲方承担人身及财产损害责任的理由"
  - "如乙方认为甲方指示、安排存在人身及财产损害危险，则乙方应向甲方说明理由并拒绝执行"
- **保险替代考量**：单位购买的意外伤害保险不能直接代替单位对员工的赔偿责任；如需增强保障，可在合同中要求承揽人自费购买相应保险
- **标题策略**：从发包方利益出发，合同标题应尽可能界定为"承揽合同"而非"劳务合同"——承揽关系是《民法典》合同编规定的有名合同（第770-787条），对定作人的责任保护更为明确

### 14.4 分包与报酬支付

- 是否禁止转承揽或限制分包，分包是否需要定作人书面同意
- 分包人的责任是否由承揽人承担（不得以分包为由免除承揽人责任）
- 报酬支付节点是否与工作进度或成果验收挂钩（不得"签合同即全额付款"）
- 材料由定作人提供时，材料的风险负担（毁损/灭失/不符合要求）是否明确

### 14.5 专项风险标签

| 标签 | 触发条件 |
|------|----------|
| `任意解除权` | 未排除定作人任意解除权，或赔偿范围约定不明 |
| `验收标准` | 验收标准空洞、程序缺失、逾期未验收无后果 |
| `独立关系` | 存在承揽/劳动/劳务混同风险（定作人实质管理承揽人人员） |
| `知识产权归属` | 成果知识产权归属未约定或约定不明 |
| `人身损害赔偿` | 定作人定作/指示/选任过失的赔偿责任未明示排除，或承揽人侵权责任分配约定不明 |
| `劳动关系混同` | 存在出勤管理、社保缴纳、固定报酬等劳动关系特征，合同标题与实质不符 |
| `分包责任` | 分包限制缺失、分包人责任归属不清 |
