## 18. 广告合同专项审查门禁

当主工作流类型路由步骤识别为广告合同时，在通用门禁之外同步核查以下专项事项。与通用门禁并行，不替代。

> **法律依据**：《广告法》(2021修正) `[法条原文]`（2018年修正后经2021年4月29日修正，主席令第81号）；《互联网广告管理办法》(2023)、《医疗广告管理办法》等部门规章。

> ⚠️ **重大变化**：《广告发布登记管理规定》（国家工商行政管理总局令第89号）已于2022年5月1日被国家市场监督管理总局令第55号废止。2021年修正的《广告法》已删除第29条中的"并向县级以上地方市场监督管理部门办理广告发布登记"和第60条对应的罚则，广告发布登记制度已被取消。当前法律框架下，广告发布方不再需要办理广告发布登记，原登记条件（法人资格、广告业务机构、广告从业人员、场所设备）可作为合同附件中的尽职调查参考。

### 18.1 双方主体资质审查

- **广告主资质审查（广告发布方义务）**（《广告法》第34条+第56条）：广告发布方是否审查了广告主的主体资格（营业执照、经营范围、特殊行业许可）。因未尽审查义务致使发布虚假广告造成消费者损害的，广告发布方与广告主承担连带赔偿责任；不能提供广告主真实名称和地址的，承担全部民事责任
- **广告发布方资质审查（广告主义务）**：广告主是否核实了广告发布方的经营资质和履约能力。广告发布登记制度已取消，但广告主仍应依据《广告法》现行条款审核发布方的经营资质（法人资格、经营范围、广告发布设备和能力），建议作为合同附件中的尽职调查材料
- **涉及特殊行业广告**（医疗、药品、医疗器械、保健食品、农药、兽药等——《广告法》第46条）：是否已在发布前取得广告审查批准文号，批准文号是否在有效期内

### 18.2 广告内容合规审查

- **绝对禁止的广告内容**（《广告法》第9条）：广告内容是否涉及使用国旗/国歌/国徽/国家机关名义、妨碍社会安定/公共秩序、妨碍环境保护、淫秽/色情/赌博/迷信/恐怖/暴力、侮辱民族/种族/宗教/性别歧视等内容
- **特殊商品广告禁止/限制**（《广告法》第15-27条）：
  - 麻醉药品、精神药品、医疗用毒性药品、放射性药品等特殊药品，药品类易制毒化学品，戒毒治疗的药品/医疗器械/治疗方法 → **绝对禁止广告**（第15条）
  - 烟草制品 → 禁止在大众媒体/公共场所发布广告（第22条）
  - 医疗/药品/医疗器械 → 不得含有功效断言/保证、不得使用治愈率/有效率数据、不得利用广告代言人作推荐（第16条）
  - 保健食品 → 不得含有功效断言、不得涉及疾病预防/治疗功能、应显著标明"本品不能代替药物"（第18条）
  - 酒类 → 不得诱导/怂恿饮酒，不得出现饮酒动作（第23条）
  - 教育培训 → 不得对升学/考试效果作明示或暗示保证（第24条）
  - 房地产 → 不得含有升值或投资回报承诺、不得以到达时间表示位置（第26条）
- **广告用语规范**：是否使用了《广告法》禁止的绝对化用语（如"最""第一""国家级""顶级""极品"等——第9条第3项）；是否有虚假或引人误解的内容（第4条/第28条——虚假广告认定标准）

### 18.3 广告发布事项的明确性

- **发布媒体和平台**：广告发布的媒体名称（电视台/广播频率/报纸/网站/APP/户外位置等）是否明确
- **广告形式和规格**：广告的表现形式（视频/音频/图文/弹窗/信息流等）、时长/版幅/分辨率等规格是否明确
- **发布时间和频次**：发布的起止日期、每日/每周/每月的具体时段、播出频次或展示次数是否精确到可直接验收
- **发布位置**：平面媒体的版面/位置/尺寸、广播电视的频道/栏目/时段、户外广告的具体位置和编号、互联网广告的页面/位置/标识"广告"字样（《互联网广告管理办法》第9条）
- **样稿/样带管理**：广告样稿/样带的提供方、审核确认程序、修改权限是否明确；是否约定了未经广告主书面同意不得更改样稿/样带
- **排期表附件**：是否将发布时间表以附件形式列明（发布时间、媒体、版位、频次等）作为验收依据

### 18.4 广告监测与验收

- **监测报告提供**（广告发布方义务）：是否约定了广告发布方按合同约定的周期（如月度/季度）提交监测报告（含发布时间、次数、截图/录音/录像等证明材料）
- **验收标准与程序**：广告主的验收权利（是否可以抽查、是否可以委托第三方监测机构）、验收异议的提出期限和方式、逾期未异议的后果
- **错播/漏播处理**：出现错播（错误的时间/媒体/内容）或漏播时的责任承担方式——是否约定退还未履行部分费用+违约赔偿/错一补二/漏一补二/等具体救济措施；错播/漏播的认定标准和举证责任

### 18.5 知识产权与第三方权利

- **广告内容知识产权归属**：广告主提供的创意/设计/文案/音乐/图片等知识产权是否明确归广告主所有；广告发布方在合同履行中产生的衍生成果的知识产权归属是否约定清晰
- **第三方权利保护**：广告内容中涉及第三方作品（摄影/音乐/肖像/美术作品等）时，由哪一方负责取得授权、承担授权费用。如因第三人权利引发侵权纠纷，责任分配是否明确（通常广告主提供内容的由广告主承担责任，但应在合同中明确约定）
- **肖像权授权**：广告中含有人物肖像的，是否取得了肖像权人的书面授权（《民法典》第1018-1022条——肖像权保护）。涉及无/限制民事行为能力人肖像时，是否取得了监护人同意
- **发布后使用限制**：合同终止后，双方对广告内容的使用和留存权限是否约定（广告发布方一般不得在合同终止后继续使用广告素材）

### 18.6 费用与审批

- **费用构成**：合同价款的具体构成是否清晰（广告位费/制作费/审批费/监测费/税费等各项费用的承担方和金额）
- **广告审查审批费用**：谁负责行政审批（通常为广告发布方），审批费用由谁承担（是否包含在合同总价款中）
- **支付节点**：付款是否与广告发布的进度或监测报告的提供挂钩（不得"签约后即全额预付"——应将大额付款分散到发布开始/中检/完成/监测报告交付等节点）

### 18.7 广告专项风险标签

| 标签 | 触发条件 |
|------|----------|
| `广告发布登记` | 合同中仍引用已废止的《广告发布登记管理规定》，或仍要求办理广告发布登记 |
| `广告内容合规` | 广告内容涉及《广告法》禁止事项（绝对禁止用语、特殊商品广告限制违规、虚假广告风险） |
| `广告审查批号` | 特殊行业广告（医疗/药品/医疗器械等）未经审查取得批准文号 |
| `主体审查缺失` | 广告发布方未审查广告主主体资格，或面临连带赔偿责任风险 |
| `错播漏播` | 错播/漏播的认定标准和具体救济措施缺失或约定模糊 |
| `知识产权归属` | 广告素材的知识产权归属和使用范围未约定或约定不明 |
| `第三人权利` | 广告中使用第三方作品或肖像未取得授权，或授权费用/侵权责任分配不明 |
| `监测验收` | 监测报告义务缺失、验收标准不明确、逾期未异议后果未约定 |
